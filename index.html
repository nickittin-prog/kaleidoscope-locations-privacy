Политика конфиденциальности приложения «Калейдоскоп локаций»

Последнее обновление: 24 октября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает, как приложение «Калейдоскоп локаций» (далее — «Приложение») собирает, использует и защищает информацию пользователей. Используя Приложение, вы соглашаетесь с условиями данной Политики.

2. Какие данные собираются и используются

Приложение запрашивает доступ к следующим данным на вашем устройстве:

  • Геолокация (GPS): Используется исключительно для отображения вашего текущего местоположения на карте и для точной установки меток. Данные о местоположении не передаются третьим лицам.
  • Камера и Фотографии: Используются исключительно для создания фотографий и прикрепления их к меткам на карте. Фотографии сохраняются в выбранной вами папке на устройстве.
  • Файлы и Хранилище: Используются для сохранения и чтения файлов меток, архивов и карт (ZIP) в выбранной вами папке.
  • Доступ к интернету (INTERNET): Используется исключительно для загрузки картографических данных (тайлов) от сервиса Яндекс.Карты. Приложение не передает и не получает пользовательские данные через интернет.

3. Передача данных третьим лицам и архитектура приложения

Приложение работает по принципу локального хранилища (local-first). Это означает, что все ваши данные (метки, тексты, фотографии, архивы) сохраняются исключительно на вашем устройстве. Приложение не имеет собственного бэкенда (серверной части), не осуществляет облачную синхронизацию и не сохраняет ваши данные в облачных хранилищах.

Для отображения карт Приложение использует SDK Яндекс.Карт (Yandex MapKit). Взаимодействие с серверами Яндекса ограничено лишь запросом графических тайлов карты. Яндекс может собирать анонимные технические данные в соответствии со своей Политикой конфиденциальности. Использование SDK регулируется Условиями использования Яндекс Карт.

4. Управление данными

Вы полностью контролируете свои данные. Вы можете удалить метки, фотографии или всю папку с данными в любой момент через файловый менеджер или через само Приложение.
